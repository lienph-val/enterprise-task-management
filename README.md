# Task Management Module

## Overview

This repository presents the **Task Management module** of a **SaaS Enterprise Management and Administration System**.

The project focuses on the analysis and design of the module, including business process modeling, database design, and user interface design. It was developed as part of my **internship project** and demonstrates the application of Business Analysis and system design techniques in an enterprise software environment.

## Contents

- **Business** – Business process and system analysis diagrams, including BPMN, Use Case, Activity, and Sequence Diagrams.
- **Database** – Entity Relationship Diagram (ERD) representing the database structure of the module.
- **UX/UI** – User interface designs and application screens created in Figma.

## Project Context

The Task Management module is designed as a component of a SaaS-based enterprise management platform, supporting task creation, assignment, tracking, approval, and management across different organizational roles.

> This repository contains analysis and design artifacts developed for the internship report.
